# Task list (prototype)

Small steps, one commit each. The founder approves how each step plays, using the "you should see" line.

## Setup
- [x] Content data: approved word list and lesson plan (`content/`)
- [x] Project memory files (`README.md`, `docs/`)
- [ ] Create the GitHub repository and push this project
- [ ] Install Vite, TypeScript, Phaser, es-hangul, ts-fsrs; get a blank page running — *you should see: a blank game window in the browser*
- [ ] Add fonts (Gowun Dodum, Pretendard, Gowun Batang, Nunito, Lora), subset for Korean — *you should see: a test page showing Korean and English in each font*

## Core systems
- [ ] Hangul block builder: letters snap into a syllable frame — *you should see: building 아, 오, 문 by tapping letters*
- [ ] Korean typing on the on-screen keyboard — *you should see: typing 엄마 and getting the right blocks*
- [ ] Review scheduler (FSRS) with first-attempt rating and the practice-vs-review rule
- [ ] Hint bubbles: tap any Korean word for audio + picture, then meaning, then next letter
- [ ] Audio playback with generated voices, every clip listed for checking
- [ ] One-click bug report (game state, log, screenshot)
